# Там, где начались мы

Романтический сайт ко дню рождения. Новое оформление: глубокий винный цвет, кремовая бумага, цветочные композиции и коллажи из ваших фотографий.

## Открыть

Дважды нажмите `index.html`. Если страница уже открыта, обновите её. Все фотографии, шрифты и иконки хранятся в папке сайта; подключение к сторонним сервисам не требуется.

## Что работает

- Четыре главы: Фуджейра, март, лето, октябрь.
- 37 настоящих фотографий. Нажатие на фото или кнопку альбома открывает просмотр всех кадров главы.
- В альбоме есть стрелки, миниатюры, переключение клавишами ← / → и свайпом по фото на телефоне. Escape закрывает просмотр.
- Письмо раскрывается по нажатию. При первом открытии осыпаются кремовые розы. Кнопка «Ещё немного цветов» повторяет эффект.
- При включённом уменьшении движения цветочная анимация отключается.

Фраза об обещании теперь звучит: «Я ещё подарю тебе тысячи букетов. Просто потому, что люблю видеть, как ты улыбаешься».

## Опубликовать через GitHub Pages

Фотографии личные. Без вашего подтверждения проект никуда не загружался. GitHub Pages обычно делает сайт доступным всем в интернете, даже если исходный репозиторий приватный.

1. Распакуйте ZIP и создайте репозиторий на GitHub.
2. Загрузите содержимое папки `our-story` в корень репозитория. `index.html` должен лежать на верхнем уровне, рядом со `style.css`, `script.js`, `gallery-data.js` и папкой `assets`.
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите `main` и `/(root)`, нажмите Save.
5. После появления адреса проверьте сайт на телефоне и только потом отправляйте ссылку.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Изменить текст

Тексты глав и письма находятся в `index.html`. Список всех фотографий — в `gallery-data.js`, короткие подписи для просмотра — в `script.js`.

## Проверка

Дополнительно увеличены мобильные тексты и области нажатия. Предусмотрены безопасные отступы iPhone вокруг выреза и нижнего индикатора, а также компактный просмотр альбомов в горизонтальной ориентации. Эти изменения проверены по коду, но не считаются визуальной проверкой на устройстве.

Проверены файлы всех фотографий и графики, ссылки на локальные ресурсы, синтаксис и основные взаимодействия в симуляции DOM. Просмотр настоящей страницы во встроенном браузере был заблокирован его политикой для адресов `file://`; финальная визуальная проверка на телефоне остаётся необходимой.

## Материалы

Личные фотографии взяты из предоставленного архива. Декоративные розы созданы отдельно для оформления. Шрифты Cormorant Garamond и Manrope распространяются по OFL; иконки Phosphor — по MIT. Тексты лицензий лежат рядом с соответствующими файлами в `assets`.
